# Development Roadmap

1. Clean-up to the client's role model (done).
2. Move to the cloud: Supabase (database), Cloudflare R2 (files), Vercel (web) + Render (API).
3. Admin/HR registers staff with a role.
4. Patient visits with slip and lab-report uploads; finalize when recovered.
5. Attendance (HR, daily), leave requests (Admin and HR approve), advance requests (Admin approves), daily tasks.
6. Hospital inventory under HR.
7. Cash management and profit/loss for Accountant and Admin.
8. Chat: doctor with patients/admin/HR/nurses; patients only with doctors and admin.
9. Patient portal: visits and reports, dues, chat.
10. One installable web app (PWA) for phones and computers (done); host with HTTPS so phones can install it.
